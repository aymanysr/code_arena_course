# Code Arena learning course

Start with M00 to see the destination and choose the right workspace. Before the Submit lessons, open Before Lesson 1 to map your teammate's repo. The teammate repo map shows what to build, why the steps depend on each other, and example folders, files, patterns, and checks. Then use the reference lessons to trace the same game's real code and tests. The first three foundation milestones are available now; later milestones stay visible as being written so you can see where the route is going.

## Start here

- [Build route](index.html) — start with M00, “See the destination,” then set up a practice workspace and learn the C-to-TypeScript basics before building game features.
- [Reference lessons](reference.html) — Start with “Before Lesson 1” to find the right folders and commands before building the Match core. Then trace real player actions through this game's code and tests.
- [Teammate repo map](reference.html#build-path) — the ordered game-build steps, with the reason, example location, pattern, and test check for each step.
- [Mission](MISSION.md) — why the course is built around understanding and rebuilding the game.
- [Explore code](source-map.html) — search the source, tests, and routes; coverage reports source freshness, not learning progress.
- CodeTours in VS Code: [1 · Big picture](../1-code-arena-big-picture.tour), [2 · Submit journey](../2-submission-journey.tour), [3 · Match and Rounds](../3-match-state-and-rounds.tour), [4 · Judging](../4-judging-and-sandbox.tour), [5 · Persistence and collaboration](../5-storage-collaboration-and-chat.tour), [6 · Rebuild](../6-rebuild-the-game.tour).
- [Maintain the course](MAINTAINING.md) — review code changes, verify lessons, and deliberately accept a new source reference.

Course activity stays in this browser. A self-check records activity only; it is not proof of mastery, rewrite parity, or 42 subject-module completion. Open Course Home or any lesson directly from this folder for offline study.
