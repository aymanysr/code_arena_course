Subject

Compute the campus access checksum

The access controller receives a list of positive integers. Read each value in order. Add odd values to the checksum. Add twice each even value. Return the final checksum.

Required interface

int loop_checksum(const int *values, int size);

Constraints

  • 1 ≤ size ≤ 16
  • Each value is between 0 and 99.
  • The input pointer is valid when size is greater than zero.
  • The result fits in a signed int.

Examples

InputExpected resultReason
[1, 2, 3, 4]161 + 4 + 3 + 8
[5, 7]12Both values are odd
