# Design the Reference Code Handoff

Type: grilling
Status: open
Blocked by: 01

## Question

How should a lesson send a beginner from a Reference path such as `packages/arena-model/src/transitions.ts` to the relevant source preview and back? Decide whether the handoff uses direct file links, pre-filled source-map searches, line ranges, or another small mechanism while keeping Reference read-only and keeping the full source explorer available for advanced lookup.
