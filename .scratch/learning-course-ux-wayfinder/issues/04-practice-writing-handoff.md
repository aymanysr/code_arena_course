# Make the Practice Writing Handoff Clear

Type: grilling
Status: open
Blocked by: 01

## Question

How should a lesson move the learner from a Practice path such as `src/transitions.ts` to writing in VS Code when the browser cannot create, inspect, or run files? Decide what the step should show about the Practice folder, file path, command, current workspace, and Team repository boundary so the learner never mistakes Reference reading for Practice work.
